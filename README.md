# telegram-agent-poster

ИИ-агент (Claude Code или Codex) ведёт ваш Telegram-канал: считает, **кто и по какой ссылке подписался**,
создаёт **именные пригласительные ссылки** для рекламы, пишет и публикует **красиво оформленные посты**
(жирный текст, цитаты, сворачиваемые цитаты, спойлеры, ссылки, кнопки), придумывает **заголовки**
и делает **картинки к постам** через подписку Codex (ChatGPT).

Репозиторий входит в курс AgentOS: его можно запустить на своём канале за вечер и показать
агента в работе вживую.

Всё работает через **Bot API** (официальный бот) на чистом Python, без внешних пакетов (кроме картинок).

## Что внутри

```
tracker/    бот-счётчик подписчиков, создание ссылок, отчёт
poster/     публикация постов, проверка перед публикацией, просмотры, шпаргалка по оформлению
skills/     навыки для агента: headlines (заголовки), codex-image (картинки)
SKILL.md    инструкция для агента (главный файл, на него указывается агент)
tests/      офлайн-тесты
.env.example  шаблон настроек
```

## Что понадобится

1. **Telegram-канал** (для демонстрации лучше тестовый) и аккаунт, который им владеет.
2. **Бот** от [@BotFather](https://t.me/BotFather): команда `/newbot`, получите токен.
   Лучше отдельный бот только для этого проекта.
3. **Бот – администратор канала** с правами «Публикация сообщений» и «Добавление участников»
   (в разных версиях Telegram называется «Приглашать пользователей» / «Add members»).
4. **Компьютер или сервер**, который остаётся включённым, пока трекер собирает данные (Mac, Linux, VPS).
5. **Python 3.11+**. Проверка: `python3 --version`.
6. **Для картинок:** Codex CLI с входом в подписку ChatGPT (`npm install -g @openai/codex`, затем `codex login`).
   Нужны Node.js и интернет. Без картинок всё остальное работает.
7. Агент: Claude Code или Codex (любой, кто читает файлы и запускает команды).

## Установка по шагам

```bash
git clone https://github.com/qwwiwi/telegram-agent-poster.git
cd telegram-agent-poster
cp .env.example .env
```

Откройте `.env` и заполните:

```
BOT_TOKEN=токен_от_BotFather
CHANNEL=@username_канала
```

`CHANNEL` – публичное имя канала с `@`. Для теста проще всего сделать канал публичным (Настройки канала,
«Тип канала», «Публичный», придумайте имя): тогда работают и публикация, и `poster/views.py`.
У приватного канала публичного имени нет: в `CHANNEL` можно указать числовой id (`-100…`), но просмотры
через `views.py` тогда прочитать нельзя – ему нужно публичное имя.

Проверьте, что всё на месте:

```bash
python3 tests/run_all.py          # офлайн-тесты, сеть не нужна
```

## Правило для ссылок-приглашений

Каждая ссылка – с именем источника и лимитом **99 999** участников (`member_limit`). Ссылки без лимита иногда ломаются и перестают пускать в канал. `create_invite.py` ставит 99 999 сам, если не указан свой `--limit`. Исключение – ссылки с одобрением заявок (`--request`): Telegram не разрешает лимит вместе с заявками.

## Запуск по частям

### 1. Трекер подписчиков

```bash
python3 tracker/bot.py
```

Бот слушает события «участник вступил / вышел» и пишет в базу `data/tracker.db` (SQLite, создаётся сам),
какая именно ссылка привела человека. Раз в час сохраняет общее число подписчиков.
Оставьте процесс запущенным: пока он не работает, события теряются (Telegram хранит их не дольше суток).
На сервере удобно запускать через `tmux`, `screen` или `systemd`.

Вместо SQLite можно использовать PostgreSQL: `pip install 'psycopg[binary]'` и в `.env`
`DATABASE_URL=postgresql://user:password@host/dbname`.

### 2. Именные ссылки

```bash
python3 tracker/create_invite.py instagram_bio
python3 tracker/create_invite.py youtube_desc --expire-days 30
python3 tracker/create_invite.py friend_anna --limit 20
python3 tracker/create_invite.py --list
```

Имя ссылки – до 32 символов; именно оно будет в отчёте. Одна ссылка – одно место размещения.
Повторный вызов с тем же именем покажет ту же ссылку (новую создаёт флаг `--new`).

### 3. Отчёт

```bash
python3 tracker/report.py --days 7
python3 tracker/report.py --days 30 --tz Europe/Berlin --json
```

Показывает: подписчиков по каждой ссылке (пришло, ушло, осталось), вступления и выходы по дням,
чистый прирост за период.

### 4. Пост

Черновик – файл в формате Telegram HTML (см. `poster/FORMATTING.md`):

```bash
python3 poster/post.py draft.html --dry-run                     # проверка и предпросмотр, ничего не отправляется
python3 poster/post.py draft.html --photo cover.png --yes       # публикация
python3 poster/post.py draft.html --button "Подписаться|https://t.me/+ссылка" --yes
python3 poster/post.py note.txt --plain --yes                   # обычный текст без разметки
python3 poster/post.py draft.html --chat @test_channel --yes    # опубликовать в другой (тестовый) канал
```

Перед отправкой автоматически работает проверка: длина (4096 символов, у подписи к фото – 1024), поиск секретов
(токены, ключи, приватные id, IP, пути к файлам) и корректность HTML. Фото с длинным текстом отправляется
как фото плюс следующее сообщение.

Только проверка: `python3 poster/check.py draft.html`.

Готовый пример для первой демонстрации: `python3 poster/post.py poster/examples/demo-post.html --dry-run`,
затем та же команда с `--yes` вместо `--dry-run`.

### 5. Просмотры

```bash
python3 poster/views.py
```

Читает публичную страницу `t.me/s/<канал>` (без токена) и записывает просмотры вместе с возрастом поста
в `data/views-history.jsonl`. Сравнивайте посты только в одном возрасте (например, через 24 часа):
просмотры растут неделями.

### 6. Картинки

```bash
skills/codex-image/scripts/run.sh "dark tech cover, friendly robot holding a glowing link icon" medium landscape
```

Скрипт печатает путь к PNG. Подробности и бриф с вопросами – `skills/codex-image/SKILL.md`.
При первом запуске создаётся собственное окружение `skills/codex-image/.venv` и ставится пакет `openai`
(он нужен как клиент к бэкенду Codex).

### 7. Заголовки

`skills/headlines/SKILL.md` – навык: как делать заголовок и первые строки, чтобы пост читали.

## Подключение к Claude Code / Codex

1. Откройте папку проекта в Claude Code (`claude`) или Codex.
2. Скажите агенту: «Прочитай `SKILL.md` в корне проекта и работай по нему».
3. Для Claude Code можно подключить навыки постоянно: скопируйте папки
   `skills/headlines` и `skills/codex-image` в `~/.claude/skills/`, а корневой `SKILL.md` положите как
   `~/.claude/skills/telegram-agent-poster/SKILL.md`. Пути в командах агент берёт относительно корня репозитория,
   поэтому запускайте его из этой папки.
4. Примеры поручений:
   - «Создай ссылки для Instagram и YouTube и покажи их».
   - «Покажи отчёт за неделю: какая ссылка сработала лучше».
   - «Напиши пост про сегодняшний отчёт, сделай три варианта заголовка, сгенерируй обложку и покажи черновик».
   - «Опубликуй». (Агент публикует только после вашего «да».)

## Безопасность

- **Токен бота живёт только в `.env`.** Файл `.env` в `.gitignore`: не коммитьте его, не присылайте
  в чаты, не вставляйте в посты. Если токен утёк – `/revoke` в @BotFather и новый токен в `.env`.
- Вместе с `.env` в git не попадают `*.db` и папка `data/`: там id и @username ваших подписчиков.
  Не публикуйте и не выгружайте эти данные.
- Bot API безопасен для вашего аккаунта: бот – отдельная сущность с ограниченными правами, которые вы выдали
  сами. Инструменты, которые входят в **личный аккаунт** (клиентские библиотеки, сессии), рискуют блокировкой
  аккаунта и дают агенту доступ ко всем вашим перепискам. В этом проекте личный аккаунт не используется.
- Давайте боту только нужные права: публикация сообщений и приглашение пользователей. Не давайте права
  удалять сообщения и банить, если они не нужны.
- Агент публикует только после вашего просмотра. Это правило записано в `SKILL.md`, а команда `post.py` без
  `--yes` не отправит ничего без вашего подтверждения в терминале.
- Проверка перед публикацией ловит очевидные утечки, но не заменяет внимательного чтения.
- Не накручивайте подписчиков и не рассылайте приглашения массово: это нарушает правила Telegram.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| `chat not found` | неверный `CHANNEL` или бот не добавлен в канал |
| `not enough rights` | выдайте боту права администратора (публикация, приглашение) |
| Отчёт пустой | трекер не был запущен; запустите `tracker/bot.py` и подождите вступлений |
| `Conflict: terminated by other getUpdates` | запущено два трекера или у бота настроен webhook: используйте отдельного бота |
| `can't parse entities` | ошибка в HTML: `python3 poster/check.py draft.html` |
| `Codex auth не найден` | выполните `codex login` |
