# Шпаргалка: оформление постов в Telegram (режим HTML)

`post.py` отправляет текст с `parse_mode=HTML`. Ниже – всё, что понимает Telegram, и примеры
красивых постов. Любой черновик проверяется командой
`python3 poster/check.py draft.html` (или `post.py draft.html --dry-run`).

## Теги

| Что получить | Как написать |
|---|---|
| **Жирный** | `<b>текст</b>` |
| *Курсив* | `<i>текст</i>` |
| Подчёркнутый | `<u>текст</u>` |
| ~~Зачёркнутый~~ | `<s>текст</s>` |
| Спойлер (скрыт, пока не нажмут) | `<tg-spoiler>текст</tg-spoiler>` |
| Ссылка | `<a href="https://example.com">текст ссылки</a>` |
| Код в строке | `<code>python3 poster/post.py</code>` |
| Блок кода | `<pre><code class="language-bash">команда</code></pre>` |
| Цитата | `<blockquote>текст</blockquote>` |
| Сворачиваемая цитата (видны 3 строки, дальше «раскрыть») | `<blockquote expandable>длинный текст</blockquote>` |

Теги можно вкладывать друг в друга (`<b><i>жирный курсив</i></b>`), но:

- закрывать нужно в обратном порядке: `<b><i>…</i></b>`, а не `<b><i>…</b></i>`;
- внутри `<code>` и `<pre>` другое форматирование не работает;
- `<blockquote>` внутри `<blockquote>` не вкладывается;
- `<span>` допустим только как `<span class="tg-spoiler">`.

Не существует: `<br>`, `<p>`, `<div>`, `<h1>`…`<h6>`, `<ul>`/`<li>`, `<img>`. Абзацы – пустая
строка, переносы – обычный Enter, списки – строки с «•» или «1.».

## Экранирование

В обычном тексте три символа пишутся сущностями:

| Символ | Писать |
|---|---|
| `<` | `&lt;` |
| `>` | `&gt;` |
| `&` | `&amp;` |

Если файл – обычный текст без разметки, запустите `post.py` с флагом `--plain`: он экранирует всё сам.

## Лимиты

- Текстовое сообщение – до **4096** видимых символов (теги не считаются).
- Подпись к фото – до **1024** видимых символов. Длиннее: фото уйдёт отдельно, текст – следующим
  сообщением (`post.py` делает это сам).
- Кнопка под постом: `--button "Текст|https://ссылка"` (повторяйте флаг для нескольких кнопок,
  каждая на своей строке).
- Длина поста: 400–1500 символов читают до конца; первые ~300 символов видны до «Показать полностью» –
  там должна быть суть и крючок.

## Структура красивого поста

1. Первая строка – заголовок жирным (одна мысль, без точки в конце).
2. Крючок: 1–2 строки, зачем читать дальше.
3. Тело: короткие абзацы по 1–3 строки, пустая строка между ними.
4. Выносной блок: список, цитата или код.
5. Финал: вопрос или призыв к одному действию. Кнопка-ссылка вместо длинного URL в тексте.

Эмодзи – по делу: 0–3 на пост, как маркер, а не украшение каждой строки.

## Пример 1. Короткий анонс

```html
<b>Агент теперь ведёт канал сам</b>

Он считает, кто и по какой ссылке пришёл, пишет посты и рисует обложки.
Я только читаю черновик и нажимаю «опубликовать».

<blockquote>Правило: ни одного поста без моего просмотра.</blockquote>

Какую рутину вы бы отдали агенту первой?
```

Публикация: `python3 poster/post.py announce.html --dry-run`, затем `--yes`.

## Пример 2. Пост со списком, спойлером и сворачиваемой цитатой

```html
<b>3 ссылки – 3 источника трафика</b>

Раньше я видел только «+5 подписчиков». Теперь у каждой площадки своя ссылка:

• <code>instagram_bio</code> – ссылка в шапке профиля
• <code>youtube_desc</code> – описание под видео
• <code>friend_anna</code> – личная рекомендация

Результат недели: <tg-spoiler>лучше всех сработал YouTube – 14 из 23 подписчиков</tg-spoiler>

<blockquote expandable>Как это устроено: бот получает событие «участник вступил», видит имя
пригласительной ссылки и записывает его в базу. Отчёт группирует вступления по именам ссылок.
Агент создаёт ссылку командой <code>create_invite.py имя</code> и подставляет её в нужное место.
Утечек нет: бот видит только то, что Telegram и так показывает администратору.</blockquote>

Где у вас лучше всего работает трафик?
```

## Пример 3. Пост с кодом и ссылкой

```html
<b>Один файл – один пост</b>

Черновик лежит в файле, публикация – одна команда:

<pre><code class="language-bash">python3 poster/post.py draft.html --photo cover.png --yes</code></pre>

Подробности – в <a href="https://example.com/guide">гайде</a>.
```

(Подставьте свою ссылку вместо `example.com`.)

## Чего не публиковать

`check.py` блокирует пост, если находит токен бота, ключ API, приватный ключ, id приватного
чата, внутренний IP или локальный путь к файлам. Это защита от случайной утечки, а не замена
глазам: перед публикацией перечитайте текст.
