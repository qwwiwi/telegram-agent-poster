# Реестр пресетов бренда

`brands.json` описывает пресеты: набор референсных картинок (с ролями) и заметки о стиле.
Бриф подключает пресет полем `"preset": "<имя>"`; референсы пресета идут первыми, затем – свои
референсы брифа. Роль можно отключить полем `"preset_replace_roles": ["logo"]`.

Как добавить свой пресет:

1. Положите картинки (png/jpg/webp) на свой диск – в репозиторий их класть не нужно.
2. Добавьте в `brands.json` пресет: `references` (абсолютные пути, у каждого `role`),
   `style_notes`, `avoid`.
3. Проверьте: `python3 scripts/brief.py presets`.

Роли референсов: subject, face, style, logo, background, layout, clothing.
Фото человека используйте только свои или с письменного согласия человека.
SVG-логотип сначала растеризуйте в png: подписка принимает только png/jpg/webp.
